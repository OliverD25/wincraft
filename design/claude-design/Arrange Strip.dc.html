WinCraft · WindowDeck plugin

WindowDeck, grouped by monitor and desktop

One band per virtual desktop, current desktop first. Inside a band, one column per monitor in physical left-to-right order, so WindowDeck is a map of the desk. Columns size by demand: a sparse monitor takes only the width its cards need (never more than its proportional share), the busiest monitor takes the rest, and an empty monitor collapses to a 40 px rail that widens into a drop box while a card is dragged. Windows keep their order inside a column; dragging across a column boundary moves the window to that monitor on restore. Same tokens as the settings window. 1440 wide artboard; WindowDeck scrolls vertically only.

Hide the hint strip: Ctrl + H

Ctrl + H hides or shows the hint strip at the bottom. WindowDeck gets shorter by the strip's height and the cards stay where they are. The choice is remembered for the next time WindowDeck opens. While the strip is hidden, a small "Ctrl + H Hints" label at the right of the header shows how to get it back.

Hover strip: keys follow the mouse

While the mouse is inside the hover strip and the strip does not have the keyboard, WindowDeck's keys go to it: digits, arrows, Enter, Esc, Ctrl+W, Ctrl+N, F2 and D. A line at the strip's foot says so for as long as it is true: 12 px regular text in text secondary, centred, in an elevated pill with the line border and row radius, 6 px above the bottom edge, drawn over the cards in every view.

Closing a window from the strip

Middle click or Ctrl+W. The card shrinks from 100 % to 85 % around its centre and fades out over 180 ms, ease-out. When the window is gone, the cards after it, in the same row and in wrapped rows below, slide into the gap over 200 ms, ease-out cubic; cards before it stay. Same in Flat, By monitor (per column; ghosts slide and fade like cards) and the compact popup. If the window is still open 1.5 s after the ask, the card grows back from 85 % and fades in, with a "Waiting for <app>" badge at the top right of its picture in the warning colour; a narrow card gets the clock alone. The badge goes when the window closes or the strip closes. With Windows "Animation effects" off, cards change at once.

Mark all as seen: Ctrl + M

Ctrl + M, in every view, clears the orange frame of every window on all monitors and desktops and tells Windows each one stopped flashing. A line says what happened for 4 s: a pill in the elevated fill with the line border and row radius, 12 px text primary, centred 8 px above the bottom edge of the cards, drawn over them. While any card is orange, the footer gets the hint chip "Ctrl + M Mark all as seen" after Rename. The selected card keeps its neutral ring, so it never reads as orange.

Few windows: every column fits on one row

In the test build, a desktop with three windows wrapped the Centre column: card 1 and ghost 2 on the first row, ghost 3 on a second row, which doubled the band height. Right has two windows, so it counted as the busiest column and took the remaining width. Centre's width was counted from its one card only, ignoring its two ghosts, so it got the 200 px minimum. Fix: column width is measured from everything the column shows, ghosts included, and when every column fits on one row, nothing wraps.

Win+Alt+A, then a digit

Win+Alt+A waits for a digit; the digit opens WindowDeck for the app at that taskbar button. Someone who knows the number types it at once and sees nothing until WindowDeck opens. Only if no digit comes within 0.7 s do the number badges under the taskbar buttons and the small wait line fade in, as help for finding the number.

Rules for the developer

  • Name. WindowDeck is its own plugin (not part of LayoutKeeper). Palette commands: "WindowDeck: Open" and "WindowDeck: Switch taskbar hover on or off". Tray entry: "WindowDeck on taskbar hover" (a check item).
  • Ctrl + H hides or shows the hint strip. WindowDeck remembers the choice between openings. While hidden, the header shows "Ctrl + H Hints" at the right.
  • Digits inside WindowDeck: a plain digit 1–9 (0 = 10) opens the window whose card shows that number chip. Ctrl+digit jumps to the app at that taskbar button. Footer hints: "1–9 Open by number" and "Ctrl + 1–9 Taskbar button".
  • Shift + digit opens the card ten higher: Shift+1 = card 11, Shift+0 = card 20, so cards 11–20 take one key press. Cards 21 and higher use the arrow keys. When this desktop has more than ten cards, the footer shows one more chip after "1–9 Open by number": "Shift + 1–0 Cards 11–20".
  • Win+Alt+A, then a digit: the digit opens WindowDeck for the app at that taskbar button. Nothing shows at first. Only if no digit is typed within 0.7 s do the number badges under the taskbar buttons and the small wait line fade in (150 ms). A digit typed before 0.7 s opens WindowDeck with no badges ever shown. See "Win+Alt+A, then a digit" above.
  • Setting "Open WindowDeck with Win+1…9" (plugin page, Settings tab), off by default. When on, Win+digit always opens WindowDeck for that taskbar button, even for an app with one window; WindowDeck stays open after Win is released; pressing the digit again while Win is held selects the next card. Win+Shift, Win+Ctrl and Win+Alt with a number stay with Windows.
  • Sort monitors by the x of their work-area rect (EnumDisplayMonitors), ties by y. Track per column = clamp(min(content, proportional share), 200 px, …), where content = cards × 180 − 8 + 13 (one row) and proportional share = monitor width / total width × band width. The column with the most windows gets 1fr (ties → primary). Empty monitor = 40 px rail. Vertically stacked monitors get their own band row under the same desktop header.
  • Desktop bands in Windows order; the current desktop first and full opacity, others at 85 %. A desktop with no windows for this app is collapsed to its header row.
  • Empty monitor rail: dashed r4, Lucide monitor 14, name semibold text-secondary + "empty" text-disabled, rotated bottom-to-top. On drag start every rail animates to 200 px (150 ms ease-out) and shows the 112-high dashed drop box; collapses on drag end. Keyboard focus on a rail (Shift+←→) expands it the same way.
  • Card 172 wide: thumbnail 96 high (16:9 crop), 1 px border r3; title 13 px one line ellipsised. Selected card (the one Enter opens): fill text primary at 10 % and a 2 px ring in text primary at 85 %, 2 px offset, in By monitor, Flat and compact (and the picture border of a lit Flat card). Not the accent: in Classic the accent and the attention orange look alike, so the selected card read as unread. Drag highlights (insertion bar, drop box) keep the accent. Dragging: card at 60 % opacity, a 2 px accent insertion bar between neighbours.
  • Taskbar order: every card shows its taskbar position (18 px number chip before the title). The primary monitor's column (the taskbar that lists all windows) also shows ghosts for windows on other monitors at their taskbar position, so the full order reads left to right.
  • Ghost 84 × card height (128), dashed 1 px border r4, two strips split by a 1 px dashed rule. (1) Name strip 20 wide, top to bottom: monitor pill 14 wide r7, 1 px text-disabled border, Lucide arrow 8 toward the monitor over the letter L / R 10 px semibold; then the full title 12 px text-secondary rotated bottom-to-top, ellipsised to the free height (~80 px); dashed number chip 16 at the bottom. (2) Live thumbnail filling the rest (~62 × 126), centre-cropped, greyscale, 40 % alpha. Tooltip: full title + "on Right".
  • Ghosts are draggable, like cards.
  • Drag inside the primary column: the ghost moves between the cards and other ghosts. On drop it changes that window’s taskbar position, relative to its new neighbours. The window itself stays on its own monitor.
  • Drag into another monitor’s column or an empty-monitor rail: the window moves to that monitor on restore, exactly as when its real card is dragged there. After the drop it shows as a normal card in that column (and as a ghost only where the taskbar lists all windows).
  • Drag onto another desktop’s band: same as dragging its real card there.
  • While dragging: the ghost keeps its ghost look (dashed border, faded picture) at 60 % opacity; the usual 2 px accent landing bar shows between the neighbours; empty-monitor rails widen into drop boxes as for cards.
  • Click or Enter on a ghost opens its window. Middle-click closes it. Right-click opens the usual card menu.
  • Keyboard: arrow keys land on ghosts like on cards (focus ring 2 px accent, 2 px offset, outside the ghost box). With a ghost selected: Ctrl+←→ and Alt+←→ change its taskbar position (the window stays on its monitor); Ctrl+Shift+←→ moves the window to the next monitor; Ctrl+Shift+↑↓ moves it to the next desktop — the same keys as for cards.
  • Not draggable: nothing. The compact view (one or two windows on this desktop) has no ghosts, so it is unchanged.
  • Dropping a card before or after a ghost sets its taskbar position relative to that window. See the two "Dragging a ghost" artboards above.
  • A window currently on a different monitor than its saved slot gets an accent "Moved" badge until restore runs.
  • Column width (no wrap when it fits): measure each column's one-row width from everything it shows: cards at their real width (portrait monitors give narrower cards) and ghosts at 84, gap 8, plus 13 for the rule and padding. If the sum of all columns, rails and gaps fits the band, every column gets exactly that width and nothing wraps; spare width goes to the last non-empty column. Only when it does not fit does the 1fr rule apply, and then the 1fr column is the one with the largest one-row width, not the most windows. A column wraps only when it is still too narrow after that. See "Few windows: every column fits on one row" above.
  • Badges: Badges ("Moved", "Same title") sit on the thumbnail, top-right, inside a 6 px inset, never in the title row. If all text chips fit within the thumbnail width minus 12 px, they show as text in one row, gap 4. If they don’t, every chip on that card turns into an 18 × 18 icon chip (Lucide copy = Same title, arrow-right-left = Moved, 12 px) with the full text in a tooltip. The title row holds only the number chip and the title, which shrinks and ellipsises. Nothing may draw outside the card box. See "Badges on narrow cards" above.
  • Mark all as seen (Ctrl + M). Works in every view. Clears the orange mark of every window (all monitors and desktops) and tells Windows each one stopped flashing. Pill for 4 s, 8 px above the bottom edge of the cards: "Marked N windows as seen · Ctrl + Z Undo" (N = 1: "Marked 1 window as seen"), "No windows to mark as seen", or after Ctrl + Z "Orange frames are back. The taskbar stays as it is." The key in the pill is a keycap chip like the footer's. Hint chip "Ctrl + M Mark all as seen": By monitor footer after Rename, and the compact popup's hint line (dropped when the popup is too narrow), only while a card is orange. Palette: WinCraft command "Mark all windows as seen" (words: read attention orange clear flash), subtitle "N windows want attention" when N > 0; run from the palette it answers with the tray notice "WinCraft: Marked N windows as seen."
  • Orange frame (window wants attention): 2 px ring in the warning colour at 2 px offset, no fill. The selected card uses the neutral ring above, so the two never look alike.
  • "Flat" view is the old single strip per desktop, kept for single-monitor users; default is By monitor when 2+ monitors are attached.

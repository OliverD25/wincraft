ClaudeDeck

A new standalone WinCraft plugin (decided 2026-11-12 in a Q&A): a compact, vertical list of your Claude Code chats in its own small window. WindowDeck stays as it is. Classic style, with the colours and the Waiting / Working / Background / Idle wording of the page "Window Deck Claude Status" as the base. Rows never move by themselves; you drag them into an order. Picked by you on 2026-11-12: the shapes for the 9 status marks, with a setting "Status mark" that adds a short word next to each shape; and tree lines for forks.

11. Homelab servers (decided 2026-11-12)

Each server from the setting is a group under the PC chats. A server icon replaces the square colour mark of a normal group, so a server never looks like a group you made; its round dot is green when it answers and grey when not. Its line shows whether it answers, CPU and RAM, and how many PC chats wait on it. Its chats are the Remote Control chats plus any chat active in the last 24 h. A PC chat blocked by a foreground ssh command gets the new status "Waits on <server>". A click on a server chat opens Windows Terminal with ssh, in that chat's folder. A Remote Control service with no chat yet is an Idle row named after its folder, with the line "Remote Control is ready".

13. News: the latest replies of every chat (approved 2026-11-12)

With many chats at once, a chat can go Idle while its last reply matters and nobody read it. The News tab sits next to the chat list and shows every reply a chat finished in the last 24 hours, newest first, several per chat. Chats that wait for your OK or ask you a question are pinned at the top. Server chats are in it too, with the server icon and name. Each item shows the chat, its project, the time and the first three lines of the reply.

A reply is unseen when the chat finished it after you last opened that chat in the Claude app. Opening the chat makes it seen, and so does opening the item here. An unseen item has an amber dot, a bold name and full-strength text; a seen one is calmer.

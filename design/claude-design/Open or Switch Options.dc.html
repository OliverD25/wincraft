Shared rules, all three options

  • An app counts as running when it has at least one visible top-level window on any monitor or desktop. Tray-only processes do not count.
  • Enter always opens a new instance, the same as today. Nothing about the primary path changes when the app is running.
  • Shift+↵ switches to the most recently used window of that app, from any of the three options.
  • Windows are listed most recently used first, by window title only. Desktop, monitor and process details appear in the right-hand inspector when a window row is selected, never in the result list. Alt+1 to Alt+9 switch to a listed window directly.
  • Desktop summary: with the app row selected, the inspector shows "N windows on M desktops" and one line per desktop with a count and a small bar; the current desktop is labelled "this one" and its bar is accent. Ctrl+D opens the windows grouped by desktop, current desktop first; Ctrl+D or Backspace returns. The summary stays out of the result list.
  • Apps that only allow one instance (Settings, Store apps that reuse their window) show the switch action first, because a new instance is not possible.

Rules for the developer

  • Name. Shortcut manager everywhere the user sees it: plugin name, window title "WinCraft · Shortcut manager", tray item "Shortcut manager", command "Open shortcut manager" (typing "detector" still finds it). Id, folder and settings stay shortcut_detector.
  • Columns. Shortcut 200 · Status 110 · Meaning · Owner · Source 110, gap 16. Meaning and Owner share the rest half and half, each cut with "…", full text in a tooltip. Owner is text primary when known, text disabled for "unknown app".
  • Owner values. "Windows", "WinCraft", "Explorer shortcut: <name>", "<App>, probably" (from the known apps list), the app a press test found, or "unknown app". Source adds shortcut file, known apps, press test. A Windows-list combination that fails the probe shows Status Windows, Owner Windows, the plain meaning.
  • Box answer. "App · <owner> — <meaning>" in the warning colour; "WinCraft — <command>" in accent; "Windows — <meaning>" in info; "Free · no app or Windows shortcut uses it" in success. The box border turns accent while it holds a combination.
  • Answer line. Inside the box frame, under a hairline, 34 high, 13 px text secondary, buttons right-aligned in the 26 px small Secondary style. WinCraft: "WinCraft uses it: …" + Change (hotkey dialog). Shortcut file: "Explorer gives this key to the shortcut “…”" + Change + Remove key; Change turns the line into "New key for “…”:" with the pressed keys as accent keycaps, Save, Remove key, Cancel. Known app: "How to change: <app>: Settings → …" + Press it for real. Unknown app: "Unknown app. Try “Press it for real” to see which app reacts." + Press it for real. Free and Windows: no line.
  • Press it for real sends the keys once, then the line reads "Pressing it opened “<title>” from <app>." (success icon) or "Nothing visible happened in 3 s." (text disabled). A found app becomes the row's Owner with source press test. In a test copy the button is at 45 % with the tooltip "Not in a test copy".
  • Results. While the box holds a combination the toolbar filters dim to 45 % and do not apply. A 28 px line "Results for <keys>" (13 semibold) with "Show all Esc" in accent at the right, then that combination's row (selection fill), then a 28 px label "Free close to it" (12 text disabled) and up to 8 free combinations close to it, Win+Alt ones first. Esc or Show all empties the box and restores the list, filters and sort.
  • Text. Nothing below 12 px; the Ctrl+F and F5 chips are 12 px.

WinCraft · Reorder plugin

Arrange strip, grouped by monitor and desktop

One band per virtual desktop, current desktop first. Inside a band, one column per monitor in physical left-to-right order, so the strip is a map of the desk. Column width follows monitor width (proportional), so a wide centre monitor gets the wide column. Windows keep their order inside a column; dragging across a column boundary moves the window to that monitor on restore. Same tokens as the settings window. 1440 wide artboard; the strip scrolls vertically only.

Rules for the developer

  • Sort monitors by the x of their work-area rect (EnumDisplayMonitors), ties by y. Column track = monitor width / total width, min 240 px. Vertically stacked monitors get their own band row under the same desktop header.
  • Desktop bands in Windows order; the current desktop first and full opacity, others at 85 %. A desktop with no windows for this app is collapsed to its header row.
  • Monitor column with no windows shows the dashed drop target (112 high) so the user can move a window there.
  • Card 172 wide: thumbnail 96 high (16:9 crop), 1 px border r3; title 13 px one line ellipsised. Selected card: selection tint + 2 px accent focus ring at 2 px offset. Dragging: card at 60 % opacity, a 2 px accent insertion bar between neighbours.
  • A window currently on a different monitor than its saved slot gets an accent "Moved" badge until restore runs.
  • "Flat" view is the old single strip per desktop, kept for single-monitor users; default is By monitor when 2+ monitors are attached.

## (c) Suspects

A suspect is a flag that nobody uses, a flag that only documents mention, a test module of a one-off probe,
or a plugin that is not in `plugins.json`. Each one is a question for the owner.
Nothing here is removed automatically. A test written for a bug that reached a user
stays (Principle 7).

- Flag `--allow-hide-popup`: only documents mention it; no script or installer uses it (CONTRIBUTING.md, src/plugins/window_deck/README.md).
- Flag `--ddc-test`: only documents mention it; no script or installer uses it (CONTRIBUTING.md).
- Flag `--hotkey-verdict`: only documents mention it; no script or installer uses it (CONTRIBUTING.md).
- Flag `--update-now`: only documents mention it; no script or installer uses it (CONTRIBUTING.md).
- Flag `--write-plugin-index`: only documents mention it; no script or installer uses it (CONTRIBUTING.md, README.md).

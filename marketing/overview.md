# WinCraft

Status: draft
Updated: 2026-11-15
Relies on: `Win+Alt+P`, `Win+Alt+X`, `Open ClaudeDeck`, `Update WinCraft`

**The Windows 11 tools Microsoft forgot, in one small free tray app.**

## Who it is for
People who use Windows 11 all day and prefer the keyboard: developers,
people with many windows and several monitors, and people who run many
Claude Code chats at once. WinCraft replaces several small tray tools with
one, and every part can be switched off.

## How it differs
- Several separate tray tools (one per job): WinCraft is one program with
  one tray icon, one settings window and one hotkey list, and each tool is
  a plugin you can switch off (source: CONSTITUTION.md, principle 3).
